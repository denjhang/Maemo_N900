DeaDBeeF for Nokia N900

Installing

This is work in progress. When the port is more mature, I will upload debian packages to maemo.org, but for now the packages can be found here.

First you need to install Libsamplerate and libmad. The can be downloaded from maemo.org, here: http://maemo.org/packages/view/libsamplerate0/, and http://maemo.org/packages/view/libmad0/.

Then you need debian package for DeadBeef. You can find it here. Install the debian package with dpkg.

Now you can start DeaDBeeF from menu or from commandline with run-standalone.sh /opt/deadbeef/bin/deadbeef.

N900 version differences

Features:

  • Autorotation
  • Hildon menu to toggle off default GTK menu

Known problems:

  • When first time starting volume from DeaDBeeF might be on zero. Check it
  • GTK filedialog does not see all directories(?), luckily it supports typing the filepath
  • Do not select anything from Help menu, it will open non closable window (kill DeaDBeeF from xterm, if you accidentally do this)
  • Lastfm plugins passwords first letter is typed in as capital. You might want to edit it manually from ~/.config/deadbeef/config file

Compiling

DeaDBeeF can be compiled easily in scratchbox development environment. Just clone my branch, run autogen.sh, configure, make and make install. My configure args are these: 

./configure --prefix=/opt/deadbeef --enable-maemo --disable-oss --disable-alsa --disable-nullout
