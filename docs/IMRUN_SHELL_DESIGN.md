# IMRUN Shell 设计 v2（2026-10-13）

目标：全屏 ImGui 运行时 = 伪 OS。纯触摸操作（物理键会调到系统多任务，
一律不用），电阻屏点击精度有限——**一切可点目标 >= 48px**。
参考定案：**安卓平板（Honeycomb）底部系统栏**为主体，桌面网格 + 全屏
切换卡片为辅。Chrome 标签条（点击目标太小）、WP 下拉栏（需常驻手势区）
不采纳。

## 1. 屏幕分区（底部系统栏 48px + 全屏内容区）

```
+--------------------------------------------------------------+
|                                                              |
|                  内容区（432px：桌面网格 或 APP）             |
|                                                              |
+--------------------------------------------------------------+
|  [<]   [cube]  [a][b][c][d]...           12:34  78%  42C    | <- 48px 系统栏
+--------------------------------------------------------------+
```

系统栏从左到右（全部 48x48 触摸区，图标 32px 居中）：

- **BACK `[<]`**：在 APP 里=回桌面（APP 转后台保活）；在桌面=无操作
- **HOME `[cube]`**：任何状态一点回桌面（= BACK 的超集，桌面态高亮）
- **运行中 APP 图标区**（弹性宽度）：即多任务栏——Honeycomb 的 recent
  apps 条。点图标=切前台；**每个图标右下角自带 16px 红点 X**（电阻屏
  指尖能点准的最小关闭目标；卡片式关闭键在 800px 宽上太奢侈）
- 右侧固定：**时钟 HH:MM**（1 分钟刷新）、电量 %、CPU 温度
  （hw_sample 现成供给）

系统栏永远是运行时自画的 ImGui window：固定 pos、NoScrollbar、
NoFocus、先于一切绘制，APP 内容区从 y=0 到 y=432。

## 2. 桌面（HOME 的内容）

- **APP 网格 4 列**：图标 96px 触摸区（64px 图标 + 名字一行），行高
  104px，4x4 满屏 16 个 APP，多了翻页（底部两个 48px 圆点箭头）
- 数据源：扫描 /home/user/imrun/apps/*/manifest.ini，图标缺失用默认
- 网格空白处：IMRUN 版本水印，不占触摸区
- 卸载 APP：点图标进**详情页**（大图标+名字+"打开"/"卸载"两个 96px
  按钮）——不用长按语义（电阻屏按住易抖动抬起）

## 3. 系统态（状态机，互斥）

1. **DESKTOP**：网格；点图标启动（已运行则切前台）
2. **APP**：独占内容区。BACK/HOME → 桌面（APP frame() 停调，内存保活）
3. **SWITCHER**：暂不做独立卡片屏——底部运行区已经是常驻多任务，信息
  不重复。仅当后台 APP > 8 个溢出时，图标区末尾出现 `[...]` 进入横向
  滚动列表

状态转换 <1 帧（窗口显隐 + 是否调 APP 的 frame()）。

## 4. 交互细则（电阻屏 = 鼠标逻辑，零手势）

- **一切操作 = 精确点击**，电容屏那套滑动/滑动手势一律不用；电阻屏
  报点抖动大，滑动手势既难触发又误触
- 按住拖动 = 鼠标拖动的等价物，只用于两处：文本选择、窗口拖动/停靠
  （ImGui 原生行为），不做任何"手势语义"
- 可点目标下限 48px；相邻可点目标间留 8px 间隔防误触
- 列表/网格滚动用可见的箭头按钮或滚动条点击，不靠 fling
- 按压反馈：按下即绘制按下态（电阻屏无 hover，按下即反馈）
- 时钟/电量/温度为只读文本，无触摸区；无长按语义（长按=按住不放，
  电阻屏容易抖动抬起，v1 的"长按卸载"改为点击进详情页后点卸载）

## 5. 存储布局（放 /home/user，文件管理器可见）

```
/home/user/imrun/            运行时 + 全部系统数据（MyDocs 是 FAT，无执行位，不能用！）
  imrun                      运行时二进制（现有 /home/user/imrun 迁入）
  apps/                      已安装 IMAPP 解包处
    n900.imrun.tonegen/
      manifest.ini  app.so  icon.png  data/
  desk.cfg                   桌面配置（图标排序/壁纸，v0 可无）
  imrun.log                  日志
```

- **为什么不放 /home/user/MyDocs**：vfat 分区无执行权限、无符号链接、
  大小写不敏感——app.so 无法 dlopen。用户导出的大文件才建议挪 MyDocs
- rootfs /home/user ~2GB 可用，.so 级 APP 绰绰有余

## 6. 与系统的关系（不做的事）

- 不取代 hildon 状态栏（信号/蓝牙还是 Maemo 的）——IMRUN 系统栏只管
  HOME/BACK/多任务/时钟/电量
- IMAPP 不注册到 hildon 桌面：只有 IMRUN 本体有 .desktop 图标，单入口
- 锁屏/休眠：继续 osso_display_blanking_pause，不自做锁屏
- 物理键零依赖：相机对焦键等一律不绑系统功能（会跳出 IMRUN）

## 7. 实施顺序

1. shell 层抽离：gldemo_imgui.c 拆 runtime（系统栏/桌面/状态机/时钟），
   ToneGen 改造成第一个 .imapp 验证 ABI（IMAPP_SPEC v0.1）
2. APP 安装器 v0：桌面"安装"入口 = 输 .imapp 路径解包
3. 长按卸载、SWITCHER 溢出列表（体验层后置）
